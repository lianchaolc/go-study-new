## 一、程序入口
1. `package main`
   - main包代表**可执行程序**，不是代码库。
   - 如果是普通库包，写别的名字，不能直接运行。
2. `func main()`
   - Go程序**唯一入口函数**，没有返回值，无参数。
   - 程序从这里开始执行。

示例代码：
```go
package main

import "fmt"

func main() {
	fmt.Println("Hello Go")
}
```

## 二、运行命令

```
# 直接运行源码，不生成exe
go run main.go

# 编译生成可执行文件
go build main.go
```

## 三、变量定义 3 种写法

```
// 写法1：声明+指定类型
var a int = 10

// 写法2：只声明，默认零值
var b int

// 写法3：简短声明（只能写在函数内部，最常用）
c := 20
```

> 
> 注意：`:=` 不能在函数外面使用。

## 四、fmt 打印输出

```
fmt.Println("带换行打印")
fmt.Print("不带换行")
fmt.Printf("格式化打印，数字=%d", 100)
```

## 五、包导入

```
import "fmt" //单个包

// 多包导入推荐写法
import (
	"fmt"
	"time"
)
```

## 六、踩坑记录

1. Go 大括号`{`**必须和同行**，不能单独换行，否则报错。
❌错误：

```
func main()
{

}
```

✅正确：

```
func main() {

}
```

2. 导入包不使用，会编译报错。
3. 文件名可以任意，但包名统一写`package main`。
